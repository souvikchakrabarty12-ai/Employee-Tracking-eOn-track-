# Backend Modules

- auth: JWT + refresh token with role-based access.
- employees: CRUD, profile, filters, CSV/XLS import.
- routes: fixed route creation, sequencing, daily planner, history.
- geofence: office and POS geofence validation.
- attendance: clock-in/out, statuses, live dashboard feed.
- tracking: websocket live location, playback, battery-aware polling.
- analytics: KPI aggregation and report generation.
- notifications: in-app/email/whatsapp-ready abstraction.
